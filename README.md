# Assignment #6: JavaScript Basics (DOM Manipulation & Events)

This project is an individual assignment for the **Web Technologies** course at Astana IT University. It demonstrates fundamental JavaScript concepts, interaction with the Document Object Model (DOM), event handling, and building a dynamic To-Do application.

## 🛠️ Tech Stack & Tools
- **HTML5 & CSS3** for structure and styling.
- **JavaScript (ES6+)** for interactivity, DOM manipulation, and logic.
- **Git & GitHub** for version control.
- **GitHub Pages** for live deployment.

- **Part 1: Introduction to JavaScript**
    - *Task 0:* First script execution (`console.log`, `alert`)[cite: 8].
    - *Task 1:* Variables of different data types, arithmetic operations, and string concatenation[cite: 8].

- **Part 2: DOM Manipulation**
    - *Task 2:* Changing element content dynamically[cite: 8].
    - *Task 3:* Modifying styles (background color, font size)[cite: 8].
    - *Task 4:* Creating and removing list items dynamically (`createElement`, `remove`)[cite: 8].

- **Part 3: Events & Calculator**
    - *Task 5:* Mouse events (`mouseover`, `mouseout`)[cite: 8].
    - *Task 6:* Keyboard events (`keyup`) for real-time input reflection[cite: 8].
    - *Task 7:* Simple interactive calculator supporting addition, subtraction, multiplication, and division[cite: 8].

- **Part 4: Mini Project — To-Do List**
    - *Task 8:* Interactive To-Do App with task adding, deletion, completion status (strike-through), and temporary array storage[cite: 8].
